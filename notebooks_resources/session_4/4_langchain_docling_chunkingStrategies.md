## LangChain
* What is LangChain?
A framework to develop ai applications - uses abstraction for chunking, working with vector databases etc. 
Has capabilities to build agents, loading documents, calling llm api's, chains etc

### LLM Call with system prompt:
In langchain, we can represent the input and output from various entities as messages, which can act as the context for the models
Primarily, they are:
* System message: This tells the model how to behave, and provide context for interactions (This is primarily important to establishe the rules, role, and behavior of the model, and enforce consistent behavious.), example: *You are a Python coding assistant. Be concise*.
The response will always be generated in the context of python. 
* Human Message: Represents user input and interactions with the model
* AI Message - responses generated by the model(s), including textual response, tool calls, meta data etc. 
* tool message

For RAG pipeline

there are two ways:

`from langchain_core.prompts import PromptTemplate, ChatPromptTemplate`

`RAG_PROMPT = PromptTemplate(
    input_variables=["context", "question"],
    template="Answer the question based on the context below. If the answer is not contained within the context, say 'I don't know.'\n\nContext: {context}\n\nQuestion: {question}\nAnswer:",
)`

and 

`RAG_PROMPT = ChatPromptTemplate.from_messages([
    ("system", "Answer using ONLY the context below. Cite section names. Say 'I don't know' if unsure."),
    ("human", "Context:\n{context}\n\nQuestion: {question}")
])`

The fundamental difference is output type and model alignment: PromptTemplate produces a single raw string for traditional text-completion models, while ChatPromptTemplate produces a structured list of role-based messages (SystemMessage, HumanMessage) tailored for modern chat models.
